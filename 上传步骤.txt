========================================
  乐宝学习平台 —— 无 PAT 上传部署步骤
  预计 5 分钟，做完等 1-2 分钟生效
========================================

【第一步】打开仓库
  浏览器打开：https://github.com/lantu5558/english-learning
  用你的 GitHub 账号登录（owner 是 lantu5558 的那个号）

【第二步】上传这 3 个文件
  1. 点右上绿色按钮「Add file」→ 选「Upload files」
  2. 把本文件夹里的这 3 个东西**整包拖进**上传区：
       - index.html          （396 KB，覆盖旧的）
       - sw.js               （3 KB，覆盖旧的）
       - books 文件夹         （里面是本测试用 EPUB）
     ⚠️ 拖文件夹才能保住 books/ 目录结构，只拖 epub 文件会跑到根目录
  3. 页面会提示「some files already exist」——这是正常的，
     index.html 和 sw.js 就是要覆盖旧版本，别取消

【第三步】提交
  1. 拉到页面最下方，Commit changes 区域
  2. 第一格填一句说明，例如：EPUB阅读器+心灵之窗+视频兜底
  3. 保持选中「Commit directly to the main branch」
  4. 点绿色「Commit changes」

【第四步】等生效 + 验证
  1. 等 1~2 分钟（GitHub Pages 要重新构建）
  2. 打开：https://lantu5558.github.io/english-learning/
  3. 强制刷新：手机浏览器长按刷新，或在网址后加 ?v=7 再回车
  4. 验收 3 件事：
       □ 资源分类里能选到「心灵之窗」（新增分类）
       □ 添加资源时类型下拉里有「EPUB 电子书」（新类型）
       □ 打开那本 EPUB 能翻页、能看目录（新阅读器）

========================================
  出问题怎么办
========================================

Q：拖文件没反应 / 上传失败
A：改用「Add file → Create new file」，右上角有上传链接；
   或者分批传，先传 index.html 和 sw.js（关键的两个），书最后再说。

Q：传完打开还是老样子
A：Service Worker 缓存没清干净。在网址后面加 ?v=7 强制刷新；
   还不行就把 PWA/浏览器缓存清一次。

Q：EPUB 打不开、一直转圈
A：先看 books/ 目录有没有真的传上去（仓库里能看到 books/ 文件夹）。
   路径错了会 404，书就读不了。

Q：不想让这本测试书公开挂着
A：验完功能后，在仓库里点进 books/ 文件夹 → 右上角删除按钮删掉即可。
   GitHub Pages 和 OSS 都是公开读，正版书别长期挂着。
