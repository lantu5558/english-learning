# 乐宝学习 · Android 壳打包说明

## 这个壳是干什么的

它只有一个功能：**打开 https://lantu5558.github.io/english-learning/**，然后配上录音、拍照需要的权限。

网页本身**没有**被打包进 APP，所以以后改功能、改样式、修 bug 只要改网站就行，
**平板上的 APP 关掉重开就是新的，不用重新打包、不用重装。**

只有下面这几样才需要重新打一次包：APP 图标、APP 名字、权限、屏幕方向、UA（伪装成什么浏览器）。
这些定好之后基本不会再动。

---

## 一、准备工作（只做一次）

1. 电脑上装 **Android Studio**（官网 developer.android.com，装的时候一路默认即可）
2. 第一次打开会下载 SDK 和 Gradle，几个 G，耐心等它跑完

---

## 二、生成 APP 图标（只做一次）

1. Android Studio 里打开这个 `android-shell` 文件夹
2. 左边文件树，右键 `app` → **New** → **Image Asset**
3. 在 **Path** 那里选 `android-shell/icon-source.png`（已经准备好了）
4. 其他默认，点 Next → Finish

---

## 三、打出 APK

1. 等 Gradle 同步完成（右下角进度条走完）
2. 顶部菜单 **Build** → **Build Bundle(s) / APK(s)** → **Build APK(s)**
3. 右下角弹提示后点 **locate**，拿到 `app-debug.apk`

这个 debug 版家里自用完全够，不用折腾签名。

---

## 四、装到平板上（华为 / 鸿蒙 4.x PAD）

三种方法任选：

**方法 A：用数据线（最稳）**
平板开启「开发者选项 / USB 调试」后，Android Studio 直接点绿色三角运行。

**方法 B：传文件安装**
把 `app-debug.apk` 用微信/QQ/USB 传到平板，点开安装。

⚠️ **鸿蒙会拦截外部 APK**，如果装不上，去这两处放行：
- 设置 → 系统和更新 → **纯净模式** → 关掉（或安装时点「继续安装」）
- 设置 → 安全 → **更多安全设置** → **安装未知应用** → 给对应的文件管理/微信开权限

---

## 五、第一次打开，一定要允许权限

装好后第一次打开，会连续弹两个框：

1. **「是否允许录制音频」→ 点「仅在使用中允许」**
   不给的话，朗读打卡录不了音
2. **「是否允许拍照」→ 点「仅在使用中允许」**
   不给的话，拍照打卡和作业上传图片都用不了

如果当时点错了，去 设置 → 应用和服务 → 应用管理 → 乐宝学习 → 权限 里改。

---

## 六、把浏览器禁掉（这才是你真正想要的）

APP 装好、确认能用之后：

设置 → **健康使用平板** → 可用时长 / 应用限额 → 把「浏览器」设为不可用或时长 0。

这样平板就只剩「乐宝学习」这一个能上网的地方了。

---

## 七、以后改东西怎么办

| 改什么 | 怎么办 |
|--------|--------|
| 打卡规则、奖励、字幕、样式、任何功能 | 我改网站 → 你**什么都不用做**，APP 关掉重开就是新的 |
| 网页打不开 / 抽风 | 在 APP 里**往下拉一下**就是刷新 |
| APP 图标、名字、权限、UA | 改代码重新打包一次，重装覆盖即可（数据不会丢） |

---

## 八、可能遇到的问题

**B站视频还是播不了**
壳里已经把 UA 伪装成普通 Chrome、也放开了自动播放限制，但华为的 WebView 内核可能仍然拦。
如果还是不行，最终方案是把那几集视频下下来传到自己的空间（直链 mp4 在任何设备都能播，
而且还能挂字幕、能防快进）。告诉我一声，我给你下载和上传的脚本。

**点录音没反应**
权限没给。设置 → 应用管理 → 乐宝学习 → 权限 → 麦克风。

**点拍照没反应 / 选不了图**
同样是相机权限。另外确认平板上有相机应用。

**平板横竖屏**
已经设成跟随系统（sensor），横屏竖屏都能用，网站也有对应的大屏布局。

---

## 九、妈妈的手机（鸿蒙 6）怎么办

鸿蒙 6 是纯血鸿蒙，装不了 APK。妈妈那边直接用浏览器打开网址，
然后在浏览器菜单里选「添加到桌面」，效果跟 APP 图标一样。

## 十、装到学而思学习机上（另一条路，官方支持）

学而思学习机本质是一台定制 Android 平板（型号 `TALIH-PD*`、Android 12/13、WebView 内核 Chrome 111），
**所以同一个 APK 可以直接装**。但它的安装管控比华为紧，要走它自己的审核流程。

### 10.1 优先走「U 盘 + 家长审核」（官方路径，不 Root、不解锁）

这是学而思明确支持的侧载方式，也是唯一不用折腾系统的方法：

1. 把 `app-debug.apk` 放进一个 **FAT32 格式**的 U 盘（或用 Type-C 线直接传到机器存储里）
   - ⚠️ U 盘必须是 FAT32，exFAT / NTFS 学习机读不出来
2. U 盘插学习机，打开学习机自带的**「文件管理器」**，找到 APK 点一下
3. 学习机会提示 **「安装申请已发送，请等待家长审核」** —— 这是正常的，不是失败
4. 家长手机打开 **「学而思亲子」**（旧版叫「学而思智能」）APP
5. 进 **应用管理** → 切到 **「待审核」** → 找到这个安装申请 → 点 **「同意」**
6. 学习机收到后会自动安装，桌面出现「乐宝学习」图标

> 同一个流程在学而思官方社区有公开教程（给第三方教育类工具用的），是可复现的。

### 10.2 装不上时的备选（风险递增，能不用就不用）

| 方法 | 怎么做 | 风险 |
|------|--------|------|
| 学习机「设置 → 安全」里开**未知来源安装** | 开完直接用文件管理器装 | 部分型号把这个入口藏了，找不到就没戏 |
| **ADB 安装** | 连电脑敲 `adb install app-debug.apk` | 需要先开开发者选项；学而思可能屏蔽了 ADB 接口 |
| **Root / 解 BL 锁 / 刷机** | 玩机社区的做法 | ❌ **别碰**。会丢保修，且学习机内置课程会失效，孩子的学习机就废了 |

### 10.3 学而思上要额外注意的三件事

**① 别指望在应用商店里搜到**
学而思应用商店不上架浏览器类 APP（客服明确说过）。我们这个壳虽然不被当浏览器分发，
但走商店这条路本来就不通，**直接走 10.1 的 U 盘路径**。

**② 家长端随时能远程卸载**
「学而思亲子」APP 里能卸载已装应用。反过来想这也是好事 —— 哪天你觉得不好用，远程就能卸掉。

**③ 「跳转管控」对我们是好事**
学而思有页面跳转管控，孩子点外链跳其他 APP 要家长授权。
壳里已经写死了**任何链接都不外跳浏览器**，正好跟这套管控不冲突。

### 10.4 好消息：B站大概率能播

学而思的 WebView 内核是 **Chrome 111**（比不少华为机型的 WebView 新），
配合壳里已经做的 UA 伪装 + 放开自动播放，**B站在学而思上能播的概率比在华为 PAD 上高不少**。
